# Лабораторный практикум по молекулярной динамике

Этот каталог содержит шесть Jupyter Notebook: вводное занятие и пять работ по
заданию преподавателя. Текст, подписи графиков и пояснения написаны по-русски.
Расчёт выполняется существующим ядром из `src/`; формулы и физические результаты
не воспроизводятся отдельной альтернативной реализацией в ноутбуках.

## Установка и запуск

Из корневой папки проекта выполните:

```bash
uv sync --extra notebook
uv run jupyter lab
```

Откройте файл из `notebooks/`. Также можно открыть папку проекта в VS Code и
выбрать установленное окружение `.venv` как Python kernel. Ноутбуки сами находят
корень проекта по `pyproject.toml`, поэтому `src/` доступен при запуске как из
корня репозитория, так и из папки `notebooks/`.

## DEMO и FULL

В вычислительных работах в верхнем блоке Python есть переменная `MODE`.

- `DEMO` — короткая проверка кода и предварительный просмотр графиков. В ячейке
  печатаются выбранные параметры: число шагов, температур, seed и повторов.
  Такие данные не являются достаточными для окончательного физического вывода.
- `FULL` — параметры исходных экспериментов: полный размер системы, протяжённая
  траектория, исходная температурная сетка и повторы. Для работ 04–05 это может
  занять продолжительное время.

Чтобы запустить полный вариант, поменяйте `MODE = "DEMO"` на
`MODE = "FULL"` **в первой конфигурационной ячейке** соответствующего ноутбука.
Не меняйте молча размер системы или длительность и не представляйте результаты
DEMO как полный расчёт. Выбранный режим и seed автоматически входят в текстовые
сводки.

## Выполнение и сохранение

1. Откройте ноутбук и сначала прочитайте титульный лист, условия и описание
   режима.
2. Выберите `DEMO` либо `FULL`.
3. Выполните команды «Run All» / «Выполнить все ячейки» сверху вниз. Ячейки
   разделяют настройку, расчёт, анализ и построение рисунков; порядок важен,
   потому что поздние ячейки используют созданные ранее переменные.
4. Результаты отображаются под соответствующими ячейками. PNG и CSV экспортируются
   в `output/notebooks/<имя-работы>/` внутри проекта. Старые результаты из
   `output/` не используются вместо нового расчёта.
5. Перед сдачей сохраните ноутбук после успешного выполнения. В нём будут видны
   выбранный режим, код и полученные именно этим запуском графики и значения.

Если вычисление прервано, используйте «Restart Kernel and Run All» («Перезапустить
ядро и выполнить все»). Ошибка обычно указывает на ячейку и строку: проверьте,
что предыдущие ячейки выполнены и выбран kernel из `.venv`.

## Порядок работ

| Файл | Работа | Основной результат |
| --- | --- | --- |
| `00_Введение.ipynb` | Введение в Jupyter и молекулярную динамику | Потенциал двух частиц и его график |
| `01_Периодические_границы.ipynb` | Двумерный калий в NVE с PBC | Траектория, энергии, температура и 2D-давление |
| `02_Установление_равновесия.ipynb` | Диагностика установления режима | Проверка блочного эвристического критерия и оценка давления |
| `03_Углеродные_стенки.ipynb` | Калий между алмазными стенками | Траектория, реакции стенок и энергетические графики |
| `04_Фазовый_переход.ipynb` | Температурный sweep в геометрии slit-pore | Доля крупнейшего кластера и кластерная восприимчивость |

Основной код в расчётных ячейках намеренно разбит на короткие этапы. Перед
каждым таким блоком объясняется назначение вызовов `src/`, параметры и
возвращаемые значения. Не требуется предварительно знать Python: базовые
понятия последовательно вводятся в ноутбуке 00.

## Замечание об источниках параметров

Масса калия, постоянные SI, параметры углерода UFF и расстояние в геометрии
алмазной стенки имеют источники, указанные в ноутбуках и корневом `README.md`.
Для используемой в проекте пары K–K (`sigma = 0.4250 nm`, `epsilon/kB = 850 K`)
в репозитории не найдено однозначной библиографической ссылки на именно эту
пару чисел. Поэтому она обозначена как фиксированная параметризация учебной
модели, а не как точно подтверждённый универсальный потенциал реального калия.
Это ограничение явно обсуждается в отчётах. Параметры и модельное ядро не
подгоняются под ожидаемую температуру кипения.
